# DEPLOYMENT DESIGN

The deployment of CivicEye AI is designed for high availability and scalability to handle real-time urban mobility data:

* **Frontend (Vercel/Netlify):** The static assets (HTML, CSS, JS) and React/Next.js applications are deployed on Vercel for fast global CDN delivery.
* **Backend API (Google Cloud Run):** The core intelligence engine (FastAPI) runs as stateless containers on Google Cloud Run, auto-scaling based on real-time traffic and incoming civic reports.
* **Database (MongoDB Atlas):** Geolocation data, user profiles, and hazard logs are stored in a fully managed, distributed MongoDB Atlas cluster ensuring minimal latency for geospatial queries.
* **AI Processing:** Image and video processing tasks are offloaded to Google Vertex AI and Gemini APIs asynchronously to ensure the main event loop remains non-blocking.
* **Real-time Pub/Sub:** Firebase Realtime Database or WebSockets handle the push notifications for live dynamic updates (e.g., immediate rerouting when a new hazard is reported).
